# Tom's Handwriting 폰트

"Don't worry, we have hair." 문구에 사용되는 폰트입니다.

## 설치 방법

1. **TomsHandwriting.woff2** 파일을 이 폴더(`public/fonts/`)에 넣어주세요.
2. TTF만 있는 경우 [CloudConvert](https://cloudconvert.com/ttf-to-woff2) 등으로 WOFF2로 변환 후 사용할 수 있습니다.

## 저작권 / 라이선스

- **Tom's Handwriting**은 **개인용(비상업적)으로만 무료**입니다.
- **상업적 사용**(서비스/앱 수익화, 광고 등) 시에는 제작자(Omega Font Labs / Tom Murphy)에게 허가를 받거나 상업용 라이선스를 구매해야 합니다.
- 폰트 파일은 저작권으로 보호되므로, 라이선스 범위를 확인한 뒤 사용하세요.

파일이 없으면 브라우저 기본 cursive 폰트(Georgia 등)가 대신 표시됩니다.
